## 🌐 Live Infrastructure Topography

* **Domain:** [`deploywithzaeem.tech`](https://deploywithzaeem.tech)
* **DNS Routing:** 4x Anycast Redundant Node Clusters (`185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`)
* **Edge Delivery:** GitHub Pages CDN with automated SSL/TLS (Let's Encrypt)
* **CI/CD Automation:** GitHub Actions (`.github/workflows/deploy.yml`)

---

## 🚀 Key Features

* **DevOps Centric:** Designed around architecture case studies, pipeline flow diagrams, and measurable impact metrics.
* **Interactive Terminal:** Simulates bash shell commands (`curl`, `terraform plan`, `kubectl`, `gh run`).
* **Zero-Build Lightweight Footprint:** Blazing fast loading with pure HTML5, CSS3, and vanilla JavaScript.
* **Automated CI/CD:** Every push to `main` verifies syntax, checks CNAME consistency, and deploys artifacts automatically.

## 🛠️ Local Development

To view and edit the site locally:

```bash
# Clone the repository
git clone https://github.com/zaeemakhtar12/githun-portfolio.git
cd githun-portfolio

# Start a lightweight local server (Python)
python -m http.server 8000

# Open in browser
# http://localhost:8000
```
